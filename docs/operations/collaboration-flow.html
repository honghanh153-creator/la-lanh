LÁ LÀNH / CỘNG TÁC CODE

Task chung. Đổi vai theo việc.

Không chia Codex làm backend, Claude làm UI. Cả hai đều được làm xuyên module. Mỗi task có một người thực hiện và một người review, cùng đọc quyết định và bàn giao trên GitHub.

Nơi giao tiếp: GitHub Issue của task ghi mục tiêu, ai đang làm, file đang sửa, quyết định và bàn giao. Agent đọc inbox ở đầu session và khi tiếp tục. Đây không phải bot tự chạy agent nền hay tự merge code.

Branch chung

collab/integration

PR task vào branch này. PR tổng gom thay đổi vào main. PR #1 đã merge, không dùng PR cũ làm nơi điều phối. Code chưa commit trên máy không đi vào PR.

↖ Code đã review quay lại hai workspace ↗
Mỗi lần bắt đầu hoặc tiếp tục:
node scripts/collaboration-inbox.mjs
Đọc Issue, PR và bàn giao mới. Checkout sạch thì chạy sync --check, review commit rồi --apply.
Ghi bàn giao trước khi dừng. Conflict thì review, không tự đè file.
PR tổng → mainGom thay đổi đã review. Không có nghĩa production đã đổi.
Kiểm tra bản tổngFull luồng, content/UI, session, OAuth, privacy và budget.
Duyệt release → deployMột bên điều phối. Theo runbook, backup và rollback.

Ví dụ: làm Tarot dễ hiểu hơn

1. Issue ghi người dùng không hiểu bài, tiêu chí đạt và phạm vi.
2. Claude nhận thực hiện, có thể sửa cả engine, API và UI.
3. Codex review nội dung, privacy và test; góp ý trong Issue/PR.
4. Claude sửa phản hồi rồi gửi bàn giao. Review xong mới merge.
5. Task tiếp theo có thể đổi vai. Hai bên sync để nhận code đã duyệt.
