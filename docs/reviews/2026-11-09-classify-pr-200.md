## Level: L

§0: L covers any change to an API or contract. #200 changes the documented and runtime body of every
422 across `/v1` and removes two public schemas from the OpenAPI and generated TS contract. It touches
no user-visible screen and adds no data, but a public-contract change is L regardless.

## Item 1 of #224: domain 422 without a body

Fixed on `origin/collab/integration` by `47cd41a0` (PR #246, merged 06.11.2026; `git log -S RadarInvalid`).
`EmptyInputProblem` in `apps/api/app/api/input_problem.py` replaces a 422 whose `content-length` is `0`
with the same `ProblemResponse` body and `no-store`, keeping the route's other headers (cookies). This
covers `radar.py` (`except RadarError` paths, which include `RadarInvalid`, at lines 272, 302, 512) and `la_chung.py` line 154, which all
return `Response(status_code=422)`. Test: `apps/api/tests/privacy/test_empty_domain_422_problem.py`
(bodiless 422 gets the problem body and keeps a cookie; other responses untouched). PR #246 was later
reclassified M in `docs/reviews/2026-11-08-reclassify-pr-246.md`.

Remaining gap: that test uses a stand-in route, not a real radar request with
`authorization_attested=false`. No test drives `RadarInvalid` end to end through the real router.
