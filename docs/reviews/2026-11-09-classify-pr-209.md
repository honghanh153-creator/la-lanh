## Level: M

`product-development-process.md` §0: M is a change of behaviour or UI inside an existing feature, with
no new personal data and no public API change. #209 changes what Khám phá (`/insights`) shows when the
content gates reject every draft, and which status the server returns for that case. Both stay inside the
existing Insights feature.

L was considered because two endpoints now return a different status for one failure. It stays M:

- no new endpoint, field or schema; 422 and `ProblemResponse` were already in the contract, and only a
  description string was regenerated;
- the only client of these routes in the repo is the web app (`apps/web/src/shared/api/client.ts`),
  updated in the same PR; no other app or package calls them;
- no new personal data, third party, AI call, share link, payment or migration.

S does not fit: the change is visible to users.
