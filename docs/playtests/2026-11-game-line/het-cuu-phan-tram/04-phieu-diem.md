## Bảng 3 — kết quả từng mức

Người bật "đừng đoán tôi" không được tính vào ngôi đầu. Hoà thì mọi người đồng hạng cao nhất đều là "người khai cao nhất".

| Mức | Người khai cao nhất (số) | % | Số người đoán đúng (K) | Số người có phiếu đoán hợp lệ (N) | K ≤ N/3? → Lừa cả hội +3 |
|---|---|---|---|---|---|
| 1 | | | | | ☐ |
| 2 | | | | | ☐ |
| 3 | | | | | ☐ |
