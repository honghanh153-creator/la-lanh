|---|---|
| Thời lượng: mở đầu / mỗi vòng (trung bình) / lật mặt / tổng (phút) | |
| Số vòng đã chạy | |
| Số vòng đã chốt trước buổi (4 / 5) và số lượt bắt mỗi đêm | |
| Ai thắng: Người Sống (trục xuất hết) / Người Sống (hết vòng, đủ nửa số Kẻ Bị Nhập) / con ma (hết vòng) / con ma (thắng ngay) | |
| Số Kẻ Bị Nhập bị trục xuất / tổng | |
| Số người Sống bị trục xuất nhầm | |
| Số Hồn cuối buổi | |
| Thầy Pháp soi trúng Kẻ Bị Nhập (số lần) | |
| Ô thì thầm được chọn: bữa sáng / bài hát / chỗ ngồi / màu áo / túi (đếm) | |
| Akinator: đoán đúng không, bao nhiêu câu | |
| Thư của Hồn: có biệt danh nào được ghép đủ trước khi trục xuất không | |
| Số câu bản sao đủ ngưỡng 3 người để đọc (0–5) | |
| Tỷ lệ phiếu tick đồng ý | |
| Tỷ lệ người đã lên tiếng | |
| Số lần cả lớp thốt "sao nó biết" | |
| Số lần ai đó rút điện thoại quay (chỉ đếm) | |
| Có ai nói "bật đèn" không / chuyển chế độ lúc nào | |
| Số người xin chơi lại | |
| Người tổ chức lớp có muốn đặt buổi thứ hai không | |
| Số báo cáo khó chịu, bị nhắm vào hoặc sợ thật trong lúc chơi | |
| Có một số bị đưa ra làm nghi phạm từ ba vòng trở lên không (có/không) | |
